# Publishing a release

A release is a GitHub release with four files:

- `catgame3d-<version>-windows-setup.exe`: the Windows installer. It installs
  the game for the current user only, without asking for administrator
  rights, and creates shortcuts in the Start menu and on the desktop.
- `catgame3d-<version>-android.apk`: the game for the Retroid and phones.
- `catgame3d-<version>-quest.apk`: the game for the Meta Quest 3.
- `catgame3d-<version>-web.zip`: the game for the browser. Unzip it and put
  the files on any web server; the game opens from `index.html`. It does not
  open straight from the disk (`file://`), only through a server.

## How to publish

1. On GitHub, open **Actions** > **Release** > **Run workflow**.
2. Type the version in the `1.2.3` format and click **Run workflow**.

The workflow (`.github/workflows/release.yml`) does the rest:

- it checks the version and that the `v1.2.3` tag does not exist yet;
- it puts the version into the exports. The Android internal number is
  `major × 10000 + minor × 100 + patch`, so 1.2.3 becomes 10203. This is why
  minor and patch stay below 100;
- it exports Windows, Android and the web version, then downloads the
  headset plugin and exports Quest;
- it builds the installer with NSIS (`tools/installer/catgame3d.nsi`);
- it creates the tag and the release, with notes generated by GitHub.

## The game in the browser

The web version is also on GitHub Pages, at
[https://rangelreale.github.io/kid-catgame-3d-ai/](https://rangelreale.github.io/kid-catgame-3d-ai/). The workflow
`.github/workflows/pages.yml` exports and publishes the game on every push to
`master` that changes the game. Changes to the documents alone do not publish.
To publish by hand, open **Actions** > **Pages** > **Run workflow**.

The web export does not use threads. This is why it runs on GitHub Pages,
which does not send the special headers (COOP and COEP) that threads need.

## The signing key

Both APKs are signed with the same release key. Android only accepts an update
signed with the same key that installed the game. **If the key is lost,
anyone who already installed the game must uninstall it before installing the
new version.**

- The key lives in the repository secrets: `ANDROID_KEYSTORE_BASE64` (the file
  in base64), `ANDROID_KEYSTORE_USER` (the alias, `catgame3d`) and
  `ANDROID_KEYSTORE_PASSWORD`.
- The father keeps a copy of the file and the password outside Git.

To export a signed build on the computer, first set the variables
`GODOT_ANDROID_KEYSTORE_RELEASE_PATH`, `GODOT_ANDROID_KEYSTORE_RELEASE_USER`
and `GODOT_ANDROID_KEYSTORE_RELEASE_PASSWORD` and use `--export-release`.
